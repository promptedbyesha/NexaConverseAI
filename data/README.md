# Data Folder

This folder contains all datasets and data files used for training and operation of NexaConverse AI.

## Subfolders

- intents/ : JSON or YAML files defining user intents and corresponding example phrases and responses.
- entities/ : Data and definitions related to entity extraction such as keywords, synonyms, or regex patterns.
- knowledge_base/ : FAQ articles, company policies, and information resources used to answer user queries or feed the chatbot knowledge base.

## Usage

Add new data files here to expand capabilities. Ensure new intent and entity files follow existing file format conventions.
