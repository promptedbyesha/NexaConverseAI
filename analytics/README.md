# Analytics Folder

Contains scripts and web applications related to real-time monitoring, logging, and analytics dashboards for NexaConverse AI.

## Subfolders

- dashboard/: Frontend UI or API backend code for analytics visualization.
- monitoring/: Logging utilities, performance trackers, and alerting scripts.

## Usage

Extend scripts here to add new metrics, custom reports, and visualization features to optimize chatbot performance and user experience.
