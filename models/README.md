# Models Folder

Contains pretrained and fine-tuned AI models managed by NexaConverse AI.

## Subfolders

- nlp_models/ : Natural language processing models such as transformers or intent classifiers.
- dialogue_models/ : Models managing conversation flow, dialogue state tracking, and response generation.

## Usage

Place model files or serialized weights here. Use model versioning to maintain multiple iterations for testing and rollback.
