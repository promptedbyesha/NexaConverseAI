# NexaConverse AI

A scalable Conversational AI platform for customer service with advanced NLP, multi-domain adaptability, and deployment readiness.

## Features

- Intent recognition & entity extraction
- Multi-turn dialogue management
- Sentiment and emotion analysis
- Proactive engagement and multimodal inputs
- API integration and knowledge base support
- Deployment with Docker and Kubernetes

## Setup Instructions

1. Create and activate a Python virtual environment:

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
.\venv\Scripts\activate   # Windows
```

2.Install dependencies:

```bash
pip install -r requirements.txt
```

3.Run the chatbot server:

```bash
uvicorn main:app --reload
```
